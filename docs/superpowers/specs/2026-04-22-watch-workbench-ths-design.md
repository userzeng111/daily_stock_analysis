# 连续跟踪工作台与同花顺式行情区设计

**日期**: 2026-04-22

**目标**: 把现有 `/watch` 从“卡片式监测页”升级成可持续使用的盯盘工作台，补齐手动刷新/主动扫描闭环，并把中间行情区改造成接近同花顺个股日 K 页的排版与交互。

## 1. 设计结论

本轮采用三栏工作台：

- 左栏：跟踪目标列表
- 中栏：主行情区，采用同花顺个股页风格
- 右栏：候选事件、复核结论、策略解释、扫描状态

保留现有 `/watch` 路由，不新增独立页面。目标是优先让用户可以“盯盘、刷新、主动扫描、查看信号与复核”，而不是继续堆叠卡片。

## 2. 用户体验目标

- 用户可以区分“刷新已有数据”和“立即跑一轮扫描”。
- 自动监测关闭时，用户仍然可以手动扫描一次。
- 当前目标详情在新的扫描结果到来后自动同步，不再出现左侧更新、右侧停留旧数据。
- K 线区具备同花顺式基础结构：主图 K 线 + MA 线 + 副图指标 + 信息栏 + 坐标轴。
- K 线时间范围支持更长周期，不局限于 `7/30`。

## 3. 页面结构

### 3.1 顶部工具条

新增以下全局控件：

- `刷新数据`：重新拉取当前列表、事件、runtime、当前 detail，不触发扫描
- `全量扫描一次`：立即对所有 `active` 目标执行一轮扫描、复核与 summary 刷新
- `启动监测 / 停止监测`：保留现有能力
- 状态信息：显示 `运行中/已停止`、SSE 连接状态、上次扫描时间、最近一次错误

### 3.2 左栏：目标列表

- 支持搜索、状态筛选、目标类型筛选
- 支持对单目标执行：
  - 打开详情
  - 立即扫描当前目标
  - 暂停/恢复
  - 删除
- 卡片显示：
  - 名称、代码、类型、状态
  - 7 日摘要
  - 信号评分、趋势状态、最近 action
  - 更新时间

### 3.3 中栏：主行情区

采用接近同花顺个股日 K 页结构：

- 顶部信息栏：
  - 名称/代码
  - 当前选择的周期与区间
  - 日期、开、高、低、收、涨跌额、涨跌幅、成交量
  - 最新复核结论与策略信号摘要
- 周期切换：
  - 一级：`分时 / 日K / 周K / 月K`
  - 二级：当处于 `日K` 时展示 `30 / 60 / 120 / 250 / 年内`
- 当前目标操作区：
  - `仅扫描当前目标`
  - 扫描 loading 态
  - 最近一次单目标扫描状态
- 图表区：
  - 主图：蜡烛图 + MA5/10/20
  - 副图：`VOL / MACD / RSI` 切换
  - 支持十字光标、hover tooltip、基础缩放/拖拽
  - 采用 A 股习惯配色：涨红跌绿
- 主题目标支持成员切换，当前成员变化时整个主行情区同步切换

### 3.4 右栏：事件与策略面板

- 候选事件列表，支持点击后联动当前目标和当前成员
- 当前目标最近一次复核结果
- 策略解释、风险因素、支撑位、压力位
- 扫描状态面板：
  - 本轮处理目标数
  - 新候选数量
  - 最近错误

## 4. 前后端职责边界

### 4.1 后端新增或变更

#### 主动扫描接口

新增：

- `POST /api/v1/watch/runtime/scan`
  - 对所有 `active` 目标执行一轮扫描
  - 即使 runtime 关闭也允许执行
- `POST /api/v1/watch/targets/{target_id}/scan`
  - 对单目标执行一轮扫描
  - 即使 runtime 关闭也允许执行

返回统一结构：

- `accepted`: 是否已执行
- `processed_targets`
- `emitted_events`
- `last_scan_at`
- `last_error`

#### 详情接口扩展

现有 `GET /api/v1/watch/targets/{id}/detail` 从 `7/30` 扩展为：

- `timeframe`: `intraday | day | week | month`
- `window`: `30 | 60 | 120 | 250 | ytd`

说明：

- `intraday` 时忽略 `window`
- `week/month` 可先按聚合后的 bar 数返回固定窗口

#### 详情载荷扩展

当前 detail 仅返回 OHLCV 和末值状态，需补齐序列：

- `kline`
  - `date, open, high, low, close, volume`
- `overlays`
  - `ma5[]`, `ma10[]`, `ma20[]`
- `subIndicators`
  - `volMa5[]`, `volMa10[]`
  - `macd.dif[]`, `macd.dea[]`, `macd.bar[]`
  - `rsi.rsi6[]`, `rsi.rsi12[]`, `rsi.rsi24[]`
- `quoteSnapshot`
  - `prevClose`, `changeAmount`, `changePct`, `amplitude`
- `meta`
  - `timeframe`, `window`, `barCount`, `updatedAt`

### 4.2 前端新增或变更

- `/watch` 改为三栏布局
- 头部增加刷新与扫描操作
- 现有 `KlineChart` 替换为组件化行情工作台
- 详情区改成“保留旧内容 + 局部 loading”，不再整块清空
- SSE 到来时，如果影响当前 target，则自动刷新 detail

## 5. 交互规则

- `刷新数据` 只重新拉接口，不触发扫描
- `全量扫描一次` 和 `仅扫描当前目标` 都会触发后端实际扫描
- 手动扫描按钮在 runtime 关闭时仍可用
- 如果用户已展开当前目标详情，相关扫描完成后自动刷新 detail
- 如果正在扫描，按钮进入 loading 态并禁用重复点击

## 6. 技术实现建议

- 图表层优先复用 `recharts`，不要继续扩当前手写 SVG
- 先完成基础交互：
  - hover
  - crosshair
  - tooltip
  - 同步主图/副图 X 轴
- 拖拽和缩放可在第一版做基础版本，避免一次追求完全行情终端级体验

## 7. P0 / P1 划分

### P0

- 三栏工作台
- 刷新数据
- 全量扫描一次
- 仅扫描当前目标
- detail 自动同步
- 主图 K 线 + MA5/10/20
- `VOL / MACD / RSI` 副图切换
- 一级周期 `分时 / 日K / 周K / 月K`
- 二级区间 `30 / 60 / 120 / 250 / 年内`
- 顶部信息栏、tooltip、十字光标、价格轴、时间轴

### P1

- 拖拽缩放增强
- 更细的事件联动
- 目标列表分页与更高信息密度
- 更多副图参数与样式细节向同花顺继续逼近

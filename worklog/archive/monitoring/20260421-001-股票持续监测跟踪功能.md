# 问题标题

股票持续监测跟踪功能

# 用户原始诉求

关于股票自动持续监测跟踪优化和重构，对于当前系统的问股和单个股票的历史分析予以保留，但是需要增加一个自动持续监测跟踪的功能：

- 系统添加跟踪股票后，在系统运行期间可以一直进行股票跟踪，判断股票是否有阶段性买点，买点策略复用现在已经有的对应的交易策略，比如 MACD，量价对比等内容；
- 在开启系统后进入这个模块后，点击开启开启整个流程；
- 判断阶段性买点需要结合最近 1 个月的历史交易数据；
- 在判断出有阶段性买点后，将判断的信息发给 LLM，让 LLM 再次进行历史数据回测，预测这个买点是否可行；
- 需要补充板块和概念词跟踪，以及相关 ETF 的股票交易代码支持。

# 当前状态

已完成：连续跟踪模块已支持个股、ETF 与主题篮子的持续监测、7 日目标摘要、`7日 / 30日` 详情面板、K 线图、策略指标、支撑/压力位展示、theme 成员切换、成员级 latest_review，以及 runtime 周期刷新 summary。后端、前端、真实 API 烟雾测试与全量 `ci_gate` 已完成验证。
